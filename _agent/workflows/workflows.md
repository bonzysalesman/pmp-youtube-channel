# Available Workflows

## 1. PMP Strategic Analysis
**Path**: `_bmad/bmm/workflows/ba/pmp-strategic-analysis.md`
**Description**: Transforms raw business needs into strategically aligned, narrative-rich requirements using the VBA and Storyteller agents. Incorporates Conflict Auditing (TA/KDT) and ECO Mapping.

## 2. Requirement Analysis (Base)
**Path**: `_bmad/bmm/workflows/ba/analyze-requirements.md`
**Description**: Basic EARS-based requirement extraction and alignment with BABOK v3.

## 3. BA Solutioning
**Path**: `_bmad/bmm/workflows/3-solutioning/`
**Description**: Standard BMAD workflows for designing and documenting solutions.

# Usage
To run a workflow, reference its name or path and describe the input "Need". For strategic tasks, use the **PMP Strategic Analysis** workflow to ensure value-driven storytelling and ECO compliance.
