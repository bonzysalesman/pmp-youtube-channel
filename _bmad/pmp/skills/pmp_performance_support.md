# Skill: Evaluate Project Status (pmp_performance_support)

## Domain: Process

## Focus Areas
Project Metrics, Artifact Management, Progress Assessment, Status Communication, KPIs, Performance Reporting

## Description
This micro-skill enables the agent to perform the PMP ECO Task: "Evaluate project status" (Domain II, Task 9). The PM develops and monitors project metrics, manages artifacts, assesses progress against the plan, and communicates status to stakeholders.

## ECO Enablers
- Develop project metrics, analysis, and reconciliation.
- Identify and tailor needed artifacts.
- Help ensure artifacts are created, reviewed, updated, and documented.
- Help ensure accessibility of artifacts.
- Assess current progress.
- Measure, analyze, and update project metrics.
- Communicate project status.
- Continually assess the effectiveness of artifact management.

## PMP Context
- **ECO Alignment**: Domain II Process — Task 9 (2026 ECO).
- **Exam Weight**: Part of Process domain (41% of exam).
- **Approach Mix**: Predictive: status reports, earned value metrics (CPI/SPI), milestone tracking, variance analysis. Agile: velocity charts, burndown/burnup charts, sprint metrics, cumulative flow diagrams. Hybrid: high-level milestone status for governance + agile metrics for team execution.
- **AI/Sustainability Lens**: AI dashboards can automate metric collection and anomaly detection; sustainability KPIs (carbon footprint, waste metrics) are an emerging category of project status indicators.
- **Knowledge Base**: Leveraging PMP Mastery content and BABOK v3 atoms.

## Key Concepts
- Tuckman ladder (original People domain context): still relevant for understanding team performance in status — low velocity in forming/storming phases is expected.
- Earned value metrics: SPI = EV/PV (schedule efficiency), CPI = EV/AC (cost efficiency). Values below 1.0 indicate unfavorable variance.
- Artifact management: status is only as reliable as the artifacts (schedules, logs, registers) that underpin it — outdated artifacts produce misleading status.
- Status communication vs. stakeholder reporting: team-level metrics (velocity, burn rate) vs. sponsor-level status (RAG indicators, milestone forecast) require different framing.

## Usage
- Trigger at all reporting cadences: sprint reviews, weekly status meetings, milestone gates, and governance check-ins.
- Cross-reference with `pmp_artefact_management`, `pmp_communications_management`, `pmp_governance_establishment`, `pmp_finance_management`.
