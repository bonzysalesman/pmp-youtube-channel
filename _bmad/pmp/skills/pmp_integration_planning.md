# Skill: Develop Integrated Project Management Plan (pmp_integration_planning)

## Domain: Process

## Focus Areas
PM Plan Development, Approach Selection, Sustainability, Execution Strategy, Data-Driven Decision Making

## Description
This micro-skill enables the agent to perform the PMP ECO Task: "Develop an integrated project management plan and plan delivery" (Domain II, Task 1). The PM assesses project complexity, selects the development approach, creates the integrated plan, estimates effort, and uses data to inform decisions throughout.

## ECO Enablers
- Assess project needs, complexity, and magnitude.
- Recommend a project management development approach (predictive, adaptive/agile, or hybrid).
- Determine critical information requirements (e.g., sustainability).
- Recommend a project execution strategy.
- Create an integrated project management plan.
- Estimate work effort and resource requirements.
- Assess consolidated project plans for dependencies, gaps, and continued business value.
- Maintain the integrated project management plan.
- Collect and analyze data to make informed project decisions.

## PMP Context
- **ECO Alignment**: Domain II Process — Task 1 (2026 ECO).
- **Exam Weight**: Part of Process domain (41% of exam).
- **Approach Mix**: Predictive: detailed project management plan with subsidiary plans (scope, schedule, cost, quality, risk, comms, procurement, resource, stakeholder). Agile: release plan + iteration/sprint plan. Hybrid: phased delivery plan with formal baselines for high-risk phases and agile execution within phases.
- **AI/Sustainability Lens**: Sustainability requirements are now an explicit enabler — projects must determine what sustainability data to collect (carbon footprint, resource consumption, social impact). AI supports data collection, predictive modeling, and real-time plan adjustments.
- **Knowledge Base**: Leveraging PMP Mastery content and BABOK v3 atoms.

## Key Concepts
- Development approach selection factors: requirements clarity (clear = predictive; evolving = agile), risk profile, team capability, organizational culture, regulatory environment.
- Integrated plan coherence: all subsidiary plans must be consistent — schedule and resource plans must align; risk plan informs contingency reserves in the cost plan.
- Sustainability information requirements: increasingly, projects must plan for environmental impact reporting, social value measurement, and ESG compliance tracking.
- Data-driven decisions: earned value metrics, velocity trends, risk probability updates — plan maintenance is continuous, not a one-time planning event.

## Usage
- Trigger at project initiation and maintain throughout execution as the project environment changes.
