# The "Mastery Filter": Integrated Practice
### Scenario: 
A remote developer didn't attend the mandatory software training and is now using the wrong coding standard.

### The Strategic Analysis:
1. **The Task**: 1.5 (Training) + 1.11 (Virtual) + 1.10 (Understanding).
2. **The Mindset**: Don't punish. **Assess** why they missed the training.
3. **The Action**: Provide **targeted OJT** (Mentoring) and verify via **Teach-Back**.

# Common Pitfalls in WG1 Questions
- **Action without Assessment**: Jumping to "Send to training" before "Identifying the gap."
- **Command without Consensus**: Mandating a change without "Surveying stakeholders."
- **Ignoring the Virtual Context**: Applying co-located logic to a time-zone conflict.
- **Failure to Document**: Reaching an agreement but not "Updating the Artifacts."

---

# Analytical Tool: The "People Decision Tree"
1. **Is there a conflict?** -> Root Cause Analysis.
2. **Is there a skill gap?** -> Determine Modality (OJT/Course).
3. **Is there distance?** -> Asynchronous protocols.
4. **Is there confusion?** -> Consensus & Documentation.

# PMP Strategy: The "Golden 77 Seconds"
- **Task 1**: Identify the Core ECO Task (e.g., Virtual Teams).
- **Task 2**: Look for "Proactive" vs. "Reactive" answers.
- **Task 3**: Eliminate any "Fire," "Ignore," or "Escalate" answers (unless last resort).
- **Task 4**: Select the answer that provides the MOST benefit to the project with the LEAST disruption.

# Practice Scenario 1
- **Question**: A virtual team is seeing a spike in rework. The PM identifies that requirements are being interpreted differently in different countries. What is the BEST first step?
  - A) Email a stern warning to the team about quality.
  - B) Schedule a 4-hour global video conference to redo requirements.
  - C) Facilitate a prototype demo and use the "Teach-Back" method.
  - D) Hire a local quality inspector for each site.

---

# 🎯 Debrief
- **Correct Answer: C**
- **Rationale**: Demonstrations (Visual) and Teach-Back (Verification) are the highest-fidelity tools for achieving **Shared Understanding (1.10)**. This addresses the root cause (different interpretations) without the exhaustion of a 4-hour meeting (B) or the cost of extra staff (D).
