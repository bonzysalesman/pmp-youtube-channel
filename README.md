# PMP Mastery Framework: Powered by BMAD

> **A fusion of professional PMP certification content and cutting-edge Agentic AI Business Analysis.**

The **PMP Mastery Framework** is a comprehensive ecosystem designed to automate, manage, and deliver a high-quality 13-week PMP (Project Management Professional) exam preparation experience. By leveraging the **BMAD Method (BMM)**, this repository integrates structured educational content with an autonomous agentic workforce and a robust WordPress delivery platform.

---

## 🏛️ The Three Pillars

### 1. 🎓 PMP Mastery Content
A serialized 13-week study plan aligned with PMI's Examination Content Outline (ECO).
- **91 Structured Lessons**: Comprehensive coverage from Day 1 to Day 91.
- **Domain-Based Logic**: Color-coded categorization (People, Process, Business Environment).
- **Automated Generation**: Content chunks and scripts generated via AI-informed templates.

### 2. 🤖 BMAD Agentic Ecosystem
An autonomous workforce of specialized agents that manage the project lifecycle.
- **Analyst**: Executes requirements and handles specification engineering.
- **Architect**: Scans system architecture and designs technical blueprints.
- **Developer**: Handles full-stack WordPress/PHP and Node.js automation.
- **PM & QA**: Manage project governance, risk, and validation testing.
- *Powered by the Creative Intelligence Suite (CIS) for narrative and visual innovation.*

### 3. 🖥️ WP Studio Staging Platform
The interactive delivery environment for content validation and student experience testing.
- **Staging URL**: `http://localhost:8881`
- **Local Path**: `/Users/bonzysalesman/Studio/pmp-exam-prep`
- **Real-time Analytics**: Integrated domain-specific progress tracking for students.
- **Role-Based Experience**: Customized navigation for Students, Instructors, and Administrators.

## 🚀 Quick Start (Staging)

The project utilizes **WP Studio** as the primary staging environment.

### Prerequisites
- **WP Studio** installed on macOS.
- **Node.js 16+** for automation scripts.

### Accessing Staging
1. Open **WP Studio**.
2. Start the site **"PMP Exam Prep"**.
3. Access the dashboard at `http://localhost:8881/wp-admin`.
4. View the frontend at `http://localhost:8881`.

### Syncing Changes
Theme and plugin changes made in `understrap-child-1.2.0/` or `plugins/` should be synced to the Studio path:
- **Studio Path**: `/Users/bonzysalesman/Studio/pmp-exam-prep`
