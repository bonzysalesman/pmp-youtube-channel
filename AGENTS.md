# BMAD Agent Ecosystem: PMP Mastery Framework

This project leverages the **BMad Method (BMM)** and the **Creative Intelligence Suite (CIS)** to automate and refine the development of the PMP Mastery Framework system.

## 🚀 Agile AI-Driven Development (BMM)

These agents are designed to handle the structured development lifecycle of the project, from analysis to deployment.

### Core Development Team
| Agent | Role | Capabilities | Primary Workflow |
|-------|------|--------------|-------------------|
| **Analyst** (`analyst.md`) | Requirements Execution | Business analysis, specification engineering | `BP` (Brainstorm Project) |
| **Architect** (`architect.md`) | System Design | Architecture scanning, technical blueprints | `DA` (Document Architecture) |
| **Developer** (`dev.md`) | Full-Stack Coding | PHP/WordPress development, Node.js automation | `FD` (Feature Development) |
| **PM** (`pm.md`) | Project Governance | Milestone tracking, risk management | `PS` (Project Status) |
| **QA** (`qa.md`) | Quality Assurance | Test engineering, validation, performance auditing | `VT` (Validation Test) |

### Specialized Support
- **Tech Writer** (`tech-writer.md`): Expert in creating clear, structured documentation and Mermaid diagrams.
- **UX Designer** (`ux-designer.md`): Focuses on user journey, mobile responsiveness, and interface aesthetics.

## 🛠️ Workflows & Commands

You can trigger BMad workflows directly in your IDE to automate complex multi-step tasks:

- **/bmad-brainstorm**: Starts a facilitated ideation session.
- **/bmad-party-mode**: Brings multiple agent personas into one conversation for collaborative problem-solving.
- **/bmad-index-docs**: Updates the project's documentation index for better AI context.
- **/cis-innovation-strategy**: High-level strategic planning for business model innovation.
